› I. About

I grew up in the Middle East, received formal legal training in South Africa, worked in Cape Town and Geneva and now live at the resourceful edge of the Karoo.

I work at the intersection of knowledge, technology and organisational change, with a particular orientation towards user-centred AI enablement.

I love the part of my job where I can apply my curiosity to scrappy brownfield problems: mapping the terrain, figuring out what a system has been optimised for and exploring what changes when optimising for something else.

› III. Projects

I have been building small and simple tools since the start of my career, but now use AI extensively for prototyping, project-based upskilling and to enhance functionality of existing tools and workflows.

Project 001
Plasticity

Co-developed a mobile app and data dashboard being piloted in five African island countries using AR game design to incentivise community data collection and recycling, aiming to bridge the data gap in waste flows in African island communities using ISLANDPLAS data and the IUCN hotspotting tool. Funded by IUCN and won first place at 2025 Ocean Hackathon.

Project 002
Publishing progress tracking agent

A Copilot Studio agent with Power Automate that sorts through ECHo and JCS notification emails to show progress and determine possible issues from previous resolutions to replace regex-based inbox rules.

Project 003
Interactive house style guide

An interactive house style guide that is founded on a simple knowledge model, using AI to navigate through the model, contextualising the rule in Explore mode, generating example applications of the rule in Show me mode and testing knowledge of the rule in Test me mode.

Project 004
Task complexity screening tool

A Powershell script that reports wordcount and change density of a document, providing a basis to prioritise editorial tasks.

I am planning to incorporate the house style rule engine to flag up potential time-consuming house style fixes and in the process of researching Planned, Observed and Unplanned house style fixes from my Asana task data to determine priority and inferred actions for a particular task type.

Project 005
Final checks tool

A Python house style compliance tool which performs basic final checks on a document to ensure the final product is polished, including a manually executed link verification checklist.

Project 006
Corpus data visualisation tool

A JS/React document tranche knowledge graph visualisation tool which allows a user to visualise and interrogate the linkages between a tranche of documents, with the ability to cluster by various characteristics, like Practice Area, Document Type and show document connections where the documents link to one another.

Project 007
Billet tracker

A basic Java/SQL workflow tracker made using NetBeans IDE and used to track raw material to final product and calculate wastage at each stage for different designs, informing best practices on cost-effective use of materials and performance management in the aluminium extrusion process.
